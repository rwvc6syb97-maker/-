## 3. 交互与正常场景
导航可通过键盘与触屏到达每个内容区；当前或目标区在跳转后清楚可见，长篇经历能够直接进入并返回。电话触发拨号意图，邮件触发邮件撰写意图，InnerQuest 打开准确外链且标明外站。所有交互须具备可辨识文字、焦点状态与触屏可操作性；内容可复制、可阅读，不能依赖悬停或动画才能获得事实。可设置少量页面内展开交互，但默认/展开状态均不能丢失必需事实。
响应式验收：在 320px 手机、768px 平板、1280px 桌面宽度及浏览器放大 200% 下，正文、导航、联系方式、经历与外链均可访问；无横向内容裁切、文字互相遮盖或不可点击目标。导航与项目卡片在移动端可触摸，长文本能够换行。无障碍：语义化标题层级、可辨认链接文本、键盘可达和可见焦点；若有动效，尊重减少动态效果偏好。
信息安全与合规：仅渲染预先确认的公开文字和链接；不展示源文件以外的个人信息、内部文档、公司数据或访问凭据。第三方项目站点的内容、隐私与可用性不属于本站承诺。页面不采集访客数据，不设置登录态与追踪脚本。

## 4. 权限、限流及接口清单
权限：匿名访客仅可浏览公开页面并触发外部协议/链接；本站无管理员界面或普通用户账号，不存在管理写操作。若后续增加受限内容、管理员或登录，须重新评审权限隔离与过期凭证处理，不得在当前站点假装已实现。
限流：静态内容和浏览器侧跳转无业务调用次数限制；当前版本不接收表单请求，也没有第三方服务端调用，故无业务 API 限流策略。若未来增加服务端接口，应分别制定匿名访问限流、重复提交防护和并发策略后再开放。
接口清单：本期无业务 API。请求方式、路由、Query/Body、必填项、入参类型与返回字段均为“不适用”；电话使用 tel: 协议、邮件使用 mailto: 协议，项目链接使用 HTTPS 跳转，均非本站 API。不得为展示内容虚构后端接口或数据库表。
未来跨端约定（仅新需求评审时启用）：后端返回结构 `{code: number; message: string; data: any}`；200 成功、4xxx 客户端错误、5xxx 服务端异常；后端内部 UTC 存储，接口时间为北京时间字符串；前端/接口字段驼峰，数据库下划线且由 ORM 映射。字段名称经 PM 确认后任何角色不得私改。当前静态站无时间接口及数据库，不据此声称已满足后端要求。

## 5. 异常场景与对应错误码
本站无业务 API，因此下列异常按前端行为验收，不返回业务错误码；错误码枚举本期为空。空输入、格式错误、参数超长、重复提交：没有表单及写接口，均不适用；不得出现可误导用户的虚假提交入口。登录凭证过期与越权访问：无登录和私有资源，不适用；不得暴露管理页或内部资料。软删除：无数据存储，不适用；删除展示内容必须经 PM 确认。
第三方服务失败/外链失效：外站故障时本站其余内容保持可读，不承诺其成功加载；若可检测到链接配置错误，上线前阻断验收并修正为来源地址。网络中断：初次加载失败应由浏览器正常提示，不伪称离线可用；页面加载后外站不可达不影响已展示内容。并发请求：无写请求，反复打开页面不导致展示状态污染。频繁点击：不产生本站写请求，不显示虚假的成功提示；若未来新增接口再定义 4xxx 限流码。设备无拨号/邮件客户端：链接仍提供可复制的电话和邮箱正文，不伪称已拨打或已发送。
