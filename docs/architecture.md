# 个人站技术架构（ORCH-01）

## 依据与范围
- 产品事实及验收口径：`docs/PRD.md`、`docs/backlog.md`；个人经历内容对照只读源 `Code_20260925(2).txt`。任何事实歧义交 PM 裁定，不由技术角色改写。
- 本期为 React + Vite 静态个人站：仅匿名阅读、站内导航和浏览器的 `tel:`、`mailto:`、HTTPS 外链。没有业务 API、服务端、账户、数据库、表单或访客数据采集；DB/BE 节点 N/A，未来扩范围需 CR。
- 此文只定义拟采用的技术边界与目录，非已实现或测试通过的声明。

## 技术栈与运行
- 前端：React + Vite，建议 TypeScript、语义化 HTML、CSS；不增加运行时后端或数据库依赖。UI 负责视觉与交互契约，FE 据此实现，不能私自修改设计 token 或业务事实。
- 本地开发端口：Vite 默认 5173；本地预览构建产物默认 4173。端口被占用可临时改用其他端口，并在测试证据记录实际地址；两者均非业务 API 端口。
- 生产部署：构建后静态文件目录 `dist/`，由静态托管服务通过 HTTPS 提供；部署目标、域名和托管环境配置待发布阶段确认。不承诺离线首次加载或外站可用。

## 拟定目录与分层（由 FE 在实施时建立）
- `index.html`：静态页面入口；`src/main.tsx`：React 挂载；`src/App.tsx`：页面组合与导航。
- `src/components/`：可复用展示组件；`src/sections/`：首页及完整经历内容区；`src/content/`：经 PM 核对的公开文案数据；`src/styles/`：样式与响应式实现。
- `public/`：仅限经确认有展示授权的公开静态资源，不放源材料、内部资料、密钥或未授权品牌素材；`dist/` 为构建产物，不作为源码维护。
- `docs/contracts/ui.md` 与 `prototype/` 由 UI 负责；前端实现须服从该契约与 PM 内容基线。页面可用锚点或详情页，由 UI/FE 在保证长篇经历直达与返回路径的前提下选定，不在此预设业务路由。

## 环境变量与安全边界
- 当前业务不需要环境变量、API 地址、Token、第三方 Key 或密钥；不得为展示页虚构配置。开发与预览端口由命令参数决定，非业务配置。
- 若未来有构建时公开配置，须先经 PM 范围确认并由 ORCH 记录契约变更；Vite 中以 `VITE_` 前缀暴露的值可进入客户端产物，绝不能放秘密。需要私密 Key 时必须另行评审服务端架构，不能放在前端变量或静态资源中。
- 联系方式展示需本人上线前确认；构建包和公开页面不得包含未经授权信息、源文档、追踪脚本或访问凭据。

## 验收边界
- UI → FE → QA → PM 终验串行放行；QA 依据 PRD T01—T09 留存可复现证据，关注 320/768/1280px、200% 缩放、键盘/触屏、外链故障退化与隐私。
- 全部技术节点 PASS 后由 PM 出具产品签收；公开电话与邮箱未获本人确认不得宣称可上线。
