# UI 视觉与交互契约（UI-01）

## 1. 范围、事实与视觉方向
- 本文仅规定静态个人站的界面呈现与交互，不定义数据字段、接口、业务新增功能或前端实现文件；内容事实以 `docs/PRD.md`、`docs/backlog.md` 和 `Code_20260925(2).txt` 为准。文案示例不替代原始逐项校对；指标、任职时间与雇主名称不可由视觉设计重写。
- 定位：一份可快速扫描、可深入阅读的「HR 实务 × AI Agent 实践档案」。视觉气质克制、精致、可信；避免招聘模板式头像横幅、荧光科技插画、大面积渐变、假仪表盘和虚构绩效数字。
- 视觉主轴：暖白纸张底色、深墨绿标题、低饱和青绿交互、细线分隔及少量暖金几何序号。以排版层级和留白建立现代感；不引入人像、实拍照片、雇主/客户商标、项目截图或未经许可的品牌素材。文字可出现经 PM 核准的单位与项目名称，不以品牌 Logo 替代。
- 此期不制作原型：以下区块、布局、状态、断点即为 FE 的实施与 QA 的核对依据；不能将视觉设计稿中的占位文案直接作为产品事实发布。

## 2. 设计 token（FE 保持用途与数值，不自行改色）
| 类别 | token | 值与用途 |
| --- | --- | --- |
| 画布 | `--ui-bg` | `#F7F8F5`，全页底色 |
| 卡面 | `--ui-surface` | `#FFFFFF`，项目卡与重点信息面 |
| 主文字 | `--ui-ink` | `#19272B`，正文、标题和链接基础色 |
| 次级文字 | `--ui-muted` | `#455456`，元信息与辅助说明；不能用浅灰承担正文 |
| 链接/强调 | `--ui-accent` | `#12665E`，文字链接与重点行动；始终配合下划线或清楚的按钮轮廓，不仅靠颜色识别 |
| 链接悬停 | `--ui-accent-hover` | `#0C4D47`，悬停或按下；信息不依赖悬停出现 |
| 装饰 | `--ui-ornament` | `#B38955`，仅小范围非关键装饰，不用于小字号文字或唯一状态指示 |
| 分隔 | `--ui-border` | `#D1DAD5`，卡片边框与分隔线；交互边界如不明显须由文字和轮廓补足 |
| 焦点 | `--ui-focus` | `#064B73`，至少 2px 实线外轮廓、与控件间 2px 间隙，不得被裁切 |
| 字体 | `--ui-font` | 系统中文无衬线优先（`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `PingFang SC`, `Microsoft YaHei`, `sans-serif`）；无外部字体依赖 |
| 圆角 | `--ui-radius` | 卡片 16px；按钮/链接容器 10px；正文区域不依赖圆角判别 |
| 阴影 | `--ui-shadow` | `0 10px 32px rgba(25,39,43,.06)`，仅桌面重点卡；移动端可去除 |
- 以 4px 为基础间距：4/8/12/16/24/32/48/64px；桌面内容最大宽度 1120px，正文阅读列最大宽度 68ch；文字不得缩小到难读以换取一屏放下。文字对背景对比目标常规 ≥4.5:1、大字 ≥3:1，交互边界与焦点 ≥3:1；QA 以实际渲染状态验证，不以表内目标代替检测。
- 字号与行高：正文 16px/1.65、说明 14px/1.5、卡片标题 20px/1.35、分区标题 `clamp(24px, 3vw, 36px)`/1.25、Hero 标题 `clamp(32px, 5vw, 56px)`/1.15；强度只用常规/中等/粗三档。可随用户字体设置扩大，不以固定高度裁字。

## 3. 信息架构与首屏（单页锚点方案）
- 采用一个完整可直接阅读的长页面，无独立详情路由。顶部放「跳到主要内容」跳转链接（默认可隐藏但聚焦时可见），随后是站点身份文字与导航：关于、核心能力、重点项目、工作经历、教育与更多、联系；导航目的地均为页内实际内容标题。
- 首页顺序：Hero（`#top`）→ 核心能力（`#skills`）→ 四个重点项目（`#projects`）→ 经历导读（`#experience-intro`）→ 完整工作经历（`#experience`）→ 教育/证书与校园实践/个人特质/兴趣（`#about-more`）→ 联系（`#contact`）。锚点是 UI 内部导航建议，不是数据字段或业务 API；如命名需调整，由 FE 提出后同步 UI 契约再实现。
- Hero 首屏视觉：小字号分类眉题「HR × AI Agent」；一级标题「Alan｜邓易丰」；二级视觉引导「人力资源数字化实践者｜HR + AI Agent复合型人才」；支持原文第 97、99 行语义的两句短摘要。主要行动「查看重点项目」到项目段，次要行动「联系我」到联系段；紧邻行动显示至少一个可直接操作且可复制的电话或邮箱明文，并标注「将调用设备应用」。不可将联系方式只放在页尾或隐藏在菜单内。
- 桌面 Hero 左为标题/摘要/行动，右为纯文字「HR 实务 / Agent 落地 / 团队赋能」主题排版，不做夸张数字或个人/企业形象图；320px 时全部转为单列，优先显示姓名、定位、联系入口。视觉首屏不设占满视口的最小高度，避免小屏将联系入口推到首屏以外。
- 能力段为三个信息块：HR 全模块、数据与办公、HR-AI 数字化；摘要分别来自原文 19—27 行，不以空泛口号取代技能事实。项目段四卡按原文 35—46 行顺序：社保 SOP 知识库自动化巡检、团队 AI 赋能能力提升、人事 AI 网站产品 0-1 自研、ER 员工关系智能问答。每卡有名称、职责与原文有据的结果；不添加项目外链、效益百分比或截图。
- 经历导读突出京东任职（事实见原文 30—33 行）与「查看完整经历（6 段）」明确文本链接；链接直达 `#experience`，不能只滚到概览。可在经历段顶部添加目录，提供六个逐条跳转入口；页面加载完成后无需额外交互或展开操作，所有六段即按顺序完整可读，禁止以默认折叠隐藏关键事实。

## 4. 六段长经历与返回路径
- 完整经历用一个二级标题、六个按原始倒序排列的条目；每条用三级标题显示单位和岗位，任职日期单独为可换行的正文。顺序固定：京东集团共享服务中心、绝味食品有限公司、北京嘀嘀无限科技有限公司、北京科锐国际人力资源股份有限公司（长沙）、湖南茶悦文化产业发展集团、株洲中车时代电气；保留各自原文日期、职责和量化信息，不将交叠任职强画为连续无重叠时间轴，不把「至今」变成固定年月。
- 可用窄列序号 01—06 及细分隔线作为阅读辅助，不使用依赖横向连线对齐的时间轴；六个条目始终展示标题、日期、完整正文，京东条目中的四个项目若在项目段重复出现，也必须保证长经历中的原文事实可读。
- 经历段开头和每个条目后有「返回首页简介」到 `#top` 的可辨识链接，末尾另有「继续阅读教育与更多」；进入 `#experience` 或单条锚点后，目标标题不得被顶部导航遮盖，键盘焦点应按阅读逻辑落在目标标题或可聚焦容器，随后 Tab 可继续访问条目链接。返回顶部后焦点与视觉位置对应；浏览器后退也不得陷入焦点丢失或跳转循环。
- 教育块展示学校、专业、学历、原日期及原文已有证书与语言能力；校园实践、个人特质、兴趣作为可见子区块按原文 74—86 行组织；不要把 90—102 行的简历评价/口头面试稿新增为第七段经历。

## 6. 交互状态与无障碍
- 所有可交互元素有清晰文本名称与默认/悬停/焦点/按下状态；键盘顺序：跳转主内容 → 站点导航 → Hero 行动/联系 → 各段链接 → 页尾链接。纯装饰序号及几何元素不参与焦点，整张项目卡若不可点击不可画成按钮。点击目标不小于 44×44 CSS px；小屏可通过 padding 补足。
- 聚焦时使用 `--ui-focus` 2px 外轮廓与 2px 间隔，Tab/Shift+Tab 在浅色背景、卡片和导航均可辨；不得设 `outline: none` 且无替代。链接默认下划线或明确边框，非仅靠颜色。单页采用一个 H1、各顶层区块 H2、每个项目/岗位 H3，不能为追求字号跳级；定义 `main` 与 `nav` 语义区，并保证导航的锚点目标清晰。
- 不强制滚动动画；若添加轻微淡入或锚点平滑滚动，持续时间不超过 180ms，事实内容在无动画时直接可读；若脚本未运行，不得显示空白页并伪称内容可用；在 `prefers-reduced-motion: reduce` 下关闭动效与平滑滚动。不得使用自动播放、打字机字效、依赖鼠标悬停显露信息。

## 7. 断点、放大与验收自查
- 320px：页面左右内边距 16px、单列卡片和导航换行/滚动到实际锚点；禁止横向整页滚动、截断手机号邮箱和长机构名称；邮箱允许按合理断点换行，仍可选中复制整串。Hero 的身份、定位与至少一项联系方式在首屏可见。
- 768px：左右内边距 24px；项目卡可两列但须保证卡中文字自然换行；导航可换行而不覆盖 Hero，阅读列不强制变窄。
- 1280px：容器居中最大 1120px，左右至少 32px；Hero 可双列，四卡可两列，长经历正文维持最大 68ch 阅读宽度；背景留白不强制填满。
- 200% 缩放：以可用 CSS 视口重新流式排版而不是按设备类型锁断点；导航自然换行，联系方式不遮挡，长标题/项目卡无固定高度裁切。顶部导航若吸顶，应为锚点设置足够目标留白；更简洁方案为非吸顶导航。
- 自查（设计契约静态核对，非运行测试）：P01 首屏含定位与联系、P02 三类能力、P03 四项目、P04—P05 六段全文/直达返回与教育、P06 更多信息、P07 联系及准确外链、P08 焦点与外站提示、P09 四种视口/缩放及动效偏好、P10 失败退化和隐私均已规定。FE 实施后需运行交付契约中的构建并由 QA 实测 T01—T09；本轮没有前端工程或浏览器可验产物，不宣称其已通过。
